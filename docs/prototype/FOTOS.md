# Fotos reais dos itens de exemplo

Hoje os 11 itens de exemplo usam ilustrações originais (`frontend/public/seed/*.svg`). Para trocar por fotos reais gratuitas:

1. Baixe uma foto por item nos sites abaixo (licenças que permitem uso gratuito, inclusive em projeto acadêmico, sem pedir atribuição; confira a licença na página da foto antes de baixar).
2. Recorte em formato horizontal 4:3, largura de cerca de 1200 px, e salve como JPG com menos de 250 KB.
3. Salve em `frontend/public/seed/` com o nome da tabela, trocando a extensão `.svg` por `.jpg`.
4. Avise o Claude para apontar o seed para os `.jpg` (é uma troca de uma linha por item).
